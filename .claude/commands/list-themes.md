# List All Themes

List all available themes in the themes repository.

## Action

1. List all directories in `/Users/billklingensmith/Code/themes/themes/`
2. For each theme, check if it has a `project.json` or configuration
3. Group themes by client/brand prefix (e.g., `cob-*`, `afs-*`, `aci-*`)

## Output

Display themes grouped by client with a count for each group.
