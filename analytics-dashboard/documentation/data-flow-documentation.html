Store Level

What Aggregates

All promotions for this store in selected week(s)

  • SUM of CIV, CC, ATL
  • SUM of composite scores
  • COUNT of promotions
  • COUNT of categories
Example Scale

~93 promotions / week

One store running a full circular with all 8 categories

Used By Dashboard
  • Base View: Circulars page (row)
  • Grid View: Store column filter
  • Compare: Store vs Store
Percentile Context

Ranked against other stores within same Sub-Brand for selected week

Store Group (Version Group)

What It Is

A subset of stores within a Sub-Brand that share the same circular version (e.g., Floral A, Floral B)

Different versions may have different promotions due to regional distributors

What Aggregates
  • SUM across all stores in group
  • COUNT of stores in group
  • Same metrics as store level
Example Scale

3-5 stores / group

~279-465 promo-records per group per week

Used By Dashboard
  • Entity Selector: Group selection
  • Compare: Group vs Group
  • Useful for version performance analysis

Sub-Brand (Retailer Banner)

What It Is

The retailer banner level — e.g., Foodtown Brooklyn, Brookshire Brothers

This is the primary operating level for most retailers

What Aggregates
  • SUM across all stores
  • COUNT of stores
  • COUNT of store groups (versions)
  • All engagement metrics
Example Scale

12-50 stores / sub-brand

~1,116-4,650 promo-records per sub-brand per week

Used By Dashboard
  • Default view for most users
  • Entity Selector: Primary selection
  • All views aggregate to this level

Brand Group (Custom Analytics Group)

What It Is

A custom grouping created for analytics purposes. Can include:

  • Multiple Sub-Brands
  • Individual Stores (from any Sub-Brand)
  • Mix of both
What Aggregates
  • SUM across selected entities
  • COUNT of sub-brands included
  • COUNT of stores included
  • All engagement metrics
Example Use Cases
  • Regional comparison (NorCal vs SoCal)
  • High-performing stores across banners
  • Test vs control groups
Used By Dashboard
  • Entity Selector: Groups tab
  • Compare: Group vs Group
  • Saved for repeated analysis

Brand (Wholesaler Level)

What It Is

The top organizational level — typically a wholesaler like ARS (Allegiance Regional Services)

Contains multiple Sub-Brands (retailer banners) underneath

What Aggregates
  • SUM across all Sub-Brands
  • COUNT of sub-brands
  • COUNT of total stores
  • All engagement metrics
Example Scale

2-6 sub-brands / brand

36-200 stores / brand

~3,348-18,600 promo-records per brand per week

Used By Dashboard
  • Executive overview
  • Cross-banner comparison
  • Entity Selector: Top of tree

All Stores (Top Level)

Filter By

Single Week Selection

View data for one specific circular week. This is the default and most common selection.

Effect on Data

Filters atomic records to only those matching the selected week_num. Percentiles calculated within this single week.

Example

Week 47: Nov 18-24, 2025

Record Count

~8,835 records (95 stores × 93 promos)

Multi-Week Selection

View data across multiple weeks for trend analysis. Metrics aggregate across all selected weeks.

Effect on Data

SUM of metrics across weeks. Useful for seeing total performance over a campaign period. Percentiles calculated across the combined dataset.

4-Week Rolling View

Quick selection for the last 4 weeks of data. Common for monthly performance reviews.

Effect on Data

Automatically selects current week and 3 prior weeks. Aggregates all metrics across the 4-week period.

Quarter Selection

View data for a full quarter (13 weeks). Useful for quarterly business reviews.

Effect on Data

Aggregates 13 weeks of data. Larger dataset enables more meaningful percentile rankings.

Year to Date

All data from January 1st through current week.

Effect on Data

Largest possible dataset for the current year. Best for annual trend analysis.

Category Filter

Filter promotions by product category.

Effect on Data

Only promotions matching the selected category are included in aggregations. Percentiles recalculated within the filtered set.

Available Categories
  • Produce
  • Meat & Seafood
  • Dairy
  • Bakery
  • Frozen Foods
  • Beverages
  • Snacks & Candy
  • Household
Dashboard Behavior

Displayed as filter chip. Can be applied from Categories page drill-down or Add Filter dialog.

Deal Type Filter

Filter promotions by their deal structure.

Effect on Data

Only promotions with matching deal_type are included. Useful for analyzing which deal structures perform best.

Deal Types
  • Fixed Price ($0.44/lb)
  • BOGO (Buy One Get One)
  • BOGO 50%
  • $ Off (Dollar off)
  • # / Price (2 for $5)
  • Mix & Match
Dashboard Behavior

Displayed as filter chip. Single selection — new replaces old.

Card Size Filter

Filter promotions by their display size in the circular layout.

Effect on Data

Only promotions with matching card_size are included. Useful for analyzing visibility impact.

Card Sizes
  • 1×1 (Standard)
  • 2×1 (Wide)
  • 2×2 (Feature)
  • 3×2 (Hero)
Analysis Use

Compare performance relative to visual prominence in the circular.

Promotion Search

Text search to find specific promotions by name.

Effect on Data

Matches promotion title containing the search term. Case-insensitive partial match.

Example Searches
  • "banana" → Bananas $0.44/lb
  • "coca" → Coca-Cola 12-pack
  • "chicken" → All chicken promotions

Base View — Progressive Drill-Down

Circulars Page (Stores)

Shows stores with aggregated metrics for selected entity + week.

  • Data: agg_store_weekly
  • Columns: Store, Views, Clicks, Adds, Performance, %tile
  • Action: Click row → Detail panel
  • Drill: View Categories button
Categories Page

Shows categories with aggregated metrics. Inherits store filter if drilled.

  • Data: agg_category_weekly
  • Columns: Category, Promos, Views, Clicks, Adds, Performance, %tile
  • Action: Click row → Detail panel
  • Drill: View Promotions button
Promotions Page

Shows individual promotions. Inherits store + category filters if drilled.

  • Data: promotion_engagement_facts
  • Columns: All promotion details + metrics
  • Views: Card view or Table view
  • Detail panel: Full promotion info
Context Preservation

Filters displayed as removable chips. Clicking ✕ navigates back up hierarchy. URL params enable deep linking.

Grid View — Full Data Exploration

Data Source

Pulls directly from atomic records (promotion_engagement_facts) filtered by current entity + week selection.

Features
  • All columns visible (toggleable)
  • Sort by any column
  • Per-column filters
  • Pagination: 25, 50, 100 rows
  • Top N selector
Column Categories
  • Identity: Promo, Category, Store
  • Metrics: CIV, CC, ATL, Composite
  • Ranking: Percentile, Performance
  • Attributes: Deal Type, Card Size, Days Run
Use Cases
  • Find specific promotions
  • Export data for external analysis
  • Advanced multi-column filtering

Compare View — A/B Analysis

Panel Independence

Each panel has its own context:

  • Date selector
  • Entity selector
  • Applied filters
Comparison Types
  • Week vs Week (same entity)
  • Store vs Store (same week)
  • Category vs Category
  • Any combination
Synchronized Display

Both panels show same level of data (Circulars, Categories, or Promotions). Sorting synced across panels.

Delta Indicators

Visual indicators show difference between A and B:

  • ↑ Green: B higher than A
  • ↓ Red: B lower than A
  • Percentage difference shown
