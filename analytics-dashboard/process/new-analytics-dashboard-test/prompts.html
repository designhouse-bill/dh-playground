Foundation Setup

Create the project structure with Angular 20-inspired folder organization.

Prompt

Create a new analytics dashboard project with Angular 20-inspired folder structure: 1. Create folders: - /styles (design-tokens.css, base.css, components.css, main.css) - /components (header/, context-cards/, filters/, modals/, data-grid/, detail-panel/, shared/) - /views (categories/, promotions/, grid/) - /services (cache-manager.js, data-service.js, state-manager.js) - /data (mock-data.js, promotion-records.js) - /utils (formatters.js, dom-helpers.js, event-bus.js) - /assets (icons/) 2. Create design-tokens.css with CSS custom properties for: - Typography (Inter font family, sizes, weights) - Colors (gray scale, primary indigo, success, warning, error) - Spacing (0-16 scale) - Borders & radius - Shadows - Transitions 3. Create base.css with: - CSS reset - Typography defaults - Button components (.btn, .btn--primary, .btn--secondary) - Form components - Utility classes (.sr-only, .truncate, .tabular-nums) 4. Create index.html skeleton with proper link/script loading order.

Self-Test

  • All folders exist in correct hierarchy
  • design-tokens.css loads without errors
  • CSS variables are accessible (test: getComputedStyle(document.body).getPropertyValue('--color-primary-500'))
  • Inter font loads from Google Fonts
  • Material Symbols icons load
Auto-Fix Strategy
If CSS variables are undefined, check @import order in design-tokens.css. If fonts don't load, verify internet connection and CDN URLs.

Core Services

Implement the service layer for caching, data fetching, and state management.

Prompt

Create the core services for the analytics dashboard: 1. cache-manager.js - IndexedDB caching layer: - initDB() - Initialize IndexedDB - set(key, data, ttl) - Store with TTL - get(key) - Retrieve if not expired - remove(key), clear(), clearExpired() - getStats() - Return cache statistics 2. data-service.js - API simulation: - fetchWithCache(endpoint, dataFn, options) - getPromotions(filters), getCategories() - getPromotionDetail(id), getComparisonData() - refresh(endpoint), refreshAll() 3. state-manager.js - Centralized state: - getState(key), setState(updates) - subscribe(keys, callback), unsubscribe(id) - Convenience methods: setLoading, setError, setViewMode, setAppMode, setActiveCategory, setActivePromotion 4. utils/event-bus.js - Pub/sub pattern: - on(event, callback), off(event, callback) - emit(event, data), once(event, callback) 5. utils/formatters.js - Data formatting: - currency(value), number(value), percent(value) - compact(value), date(value), truncate(text) - percentileClass(value) 6. utils/dom-helpers.js - DOM utilities: - $(selector), $$(selector) - create(tag, attrs, children) - delegate(parent, event, selector, callback) - toggle, addClass, removeClass, show, hide - debounce(fn, delay)

Self-Test

  • CacheManager.init() resolves without error
  • CacheManager.set('test', {foo: 'bar'}) returns true
  • CacheManager.get('test') returns {foo: 'bar'}
  • StateManager.setState({isLoading: true}) updates state
  • StateManager.subscribe('isLoading', cb) triggers on change
  • EventBus.emit('test') triggers subscribed handlers
  • Formatters.currency(1234) returns '$1,234'
Console Test Commands

Data Layer

Set up mock data for promotions, categories, and entities.

Prompt

Create the data layer for the analytics dashboard: 1. promotion-records.js - Raw promotion data: - window.promotionRecordsData = [...] - Each record: storeId, storeName, weekNum, promotionId, category, title, unit, originalPrice, salePrice, dealType, civ, cc, atl 2. mock-data.js - Data generator: - weeks[] configuration (week 44-48) - brands[] with subBrands and stores hierarchy - categories[] with name, color, icon - Generate promotions with computed fields (percentile, compositeScore) - Aggregate data for category-level stats - Export as window.MockData = { weeks, brands, categories, promotions } 3. Verify data loads: - promotionRecordsData available before mock-data.js - MockData.categories has 8 categories - MockData.promotions is array of promotion objects - Each promotion has: id, name, category, dealType, civ, cc, atl, percentile

Self-Test

  • window.promotionRecordsData is defined and has records
  • window.MockData is defined
  • MockData.weeks.length === 5
  • MockData.categories.length === 8
  • MockData.promotions.length > 0
  • MockData.promotions[0].percentile is a number 0-100
Common Error
If MockData is undefined, check script loading order. promotion-records.js must load before mock-data.js.
