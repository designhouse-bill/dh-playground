Features

  • 3 Layouts: Centered, Spread, Stacked
  • Bilingual: English and Spanish support
  • Validity Pill: Shows countdown for last 2 days
  • Sticky Scroll: Optional hide-on-scroll behavior
  • 3 Presets: Standard, Minimal, Bold
  • Debug Tools: View, copy, import/export JSON config
  • Cross-tab Sync: Changes in Admin reflect in Circular via storage events

Project Structure

  • index.html - This launcher page
  • js/config.js - Shared configuration module
  • css/tokens.css - Design system tokens
  • vendor/ - Local PrimeFlex and PrimeIcons
  • circular/ - End-user banner view
  • admin/ - Configuration panel
