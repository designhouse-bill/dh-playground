Layout Panel Prototype

Interactive wireframe demonstrating the pocket modal interface, tab-based navigation, progressive disclosure, and the Layout panel for hero image positioning.

📋 Overview

The Layout panel allows users to customize hero image positioning for different card sizes (1x1 to 3x3). It's accessible from the Editor panel via contextual prompts, the Background section, or after selecting an image in the Media Repository. All editing happens within a "pocket modal" that slides up from the bottom.

📂 Tab Structure

Tabs are organized into two groups separated by a visual divider. Promotion-level tabs (left) require a selection and operate on the selected promotion. Circular-level tabs (right) are always available and operate on the entire circular.

Important: Design and Layout are different features:

  • Design tab — Typography, colors, effects, and card styling (visible in tab bar)
  • Layout panel — Hero image positioning for different card sizes (accessed via contextual links, not a tab)

The Layout panel uses progressive disclosure — users discover it when they need to customize hero positioning.

🖥 Pocket Modal Interface

The editing panels open in a pocket modal that slides up from the bottom of the screen. This keeps the data grid partially visible and provides clear context for navigation. The modal supports two heights: full (95vh) and half (55vh).

🎛 Navigation Features

Multiple navigation aids help users maintain context and move efficiently between views.

Breadcrumbs Three-Level Path
Shows "Data Grid › Editor › [Current Tab]". Clicking Data Grid closes modal. Clicking Editor returns to Editor tab.
Button Back to Editor
Visible on Media and Layout tabs. Quick return to the Editor "home base" without using breadcrumbs.
Header Promotion Context
Selected promotion name displayed prominently. Prev/Next buttons for navigating between promotions without returning to grid.
Tab Bar Direct Tab Switching
Click any tab to switch directly. Layout tab shows "NEW" badge and tooltip for first-time users.

🛠 User Flows

Three primary paths to discover and use the Layout feature.

A
Contextual Discovery (Recommended)
User edits a promotion, sees the prompt card below the Media section, clicks "Open Layout" to customize hero positioning.
Grid → Editor → Prompt Card → Layout
B
Direct Tab Access
User notices the Layout tab (with NEW badge), clicks it directly to explore the feature. Requires single promotion selected.
Grid → Layout Tab
C
From Media Repository
After selecting/changing a hero image in Media, user sees toast notification with "Customize layout" action, clicks to refine positioning.
Grid → Media → Toast Action → Layout

✅ Key Design Decisions

📄
Single Promotion for Layout
Layout panel only available when exactly one promotion is selected.
🚫
Dismissible Prompts
Prompt card can be dismissed permanently, replaced by subtle text link.
🏠
Editor as Home Base
Editor tab is the primary view. Other tabs support the editing workflow.
🔒
Tabs Disabled Without Selection
Primary tabs (Editor, Media, Design) require at least one promotion selected.

🛠 Tab Enable/Disable Rules

Tab availability changes based on selection state. This prevents users from accessing editing interfaces when there's nothing to edit.

❌
No Selection
Primary tabs disabled. Only Circular-level tabs (Promotion, Categories, Recipes) available.
✅
Single Selection
All tabs enabled. Layout panel accessible via contextual links.
⚠
Multi-Selection (2+)
Primary tabs enabled. Layout panel disabled (requires single selection).
👁
Visual Feedback
Disabled tabs have 50% opacity and show tooltip on hover explaining why.
