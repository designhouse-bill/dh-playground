⚠ Edge Cases

13 documented edge cases grouped by category. Each describes the scenario and expected behavior.

Selection Edge Cases

E1
No promotion selected
Primary tabs (Editor, Media, Design) disabled with 50% opacity. Tooltip: "Select a promotion to edit"
E2
Multiple promotions selected (2+)
Layout panel links disabled. All other primary tabs remain enabled.
E3
Category row selected
No action available. Category rows are grouping headers only.
E4
Deselect row while modal open
Modal remains open. Context preserved for current promotion.

Media Edge Cases

E5
No hero image assigned
Show "No image" placeholder. "Add Image" button available.
E6
Image fails to load
Error state with retry button. Fallback placeholder shown.
E7
Search returns no results
Empty state message: "No images found. Try different search terms."

Navigation Edge Cases

E8
Click "Data Grid" in breadcrumb
Closes modal. Returns to grid view. Selection preserved.
E9
Previous at first / Next at last item
Button disabled. Visual indicator (grayed out).
E10
Tab switch during transition
Queue the switch OR block until transition complete.

Layout Panel Edge Cases

E11
Switch card size with unsaved changes
Auto-save current size config. No confirmation needed.
E12
All 9 sizes have custom configs
Visual indicator (purple dot) on each customized size.
E13
Reset to default template
Confirmation dialog: "Reset positioning to default?"
