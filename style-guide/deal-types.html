Component Properties Reference
Common properties across all deal types
Property Type Description Example
dealType DealType Type of deal to display "amount" | "numfor" | "bogo" | "save-x" | "numslash" | "from-num" | "none"
amount number Price or discount amount 9.99
amountType AmountType Type of amount "Dollars" | "Cents" | "Percent" | "Free"
buyNumber number Quantity to buy (numfor, bogo, numslash) 2
getNumber number Quantity received (bogo) 1
amountText string Additional text label "Each", "lb", "pk"
layout string Display layout "default" | "horizontal" | "simple"
showDollarSigns string When to show $ symbol "always" | "auto"
showDecimals string When to show decimal places "always" | "auto"
